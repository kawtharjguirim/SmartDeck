# Processus Intérieur de La Gestion des Trajets

## Introduction

Cette procédure interne vise à clarifier les étapes du processus de gestion des trajets dans l'agence de voyages fictive "VoyageExpress". Elle identifie les rôles et délais pour assurer la cohérence et la rapidité du processus.

## Étape 1 : Requête de Trajet

### Rôles :
- Agent de Réception
- Agent de Connaissance

### Délais :
- Agent de Réception : 24 heures
- Agent de Connaissance : 12 heures

### Étape détaillée :
L'Agent de Réception enregistre la requête de trajet. L'Agent de Connaissance vérifie la validité de la demande et le délai est dépassé si le demandeur ne reçoit pas de réponse. Si validé, le demandeur reçoit une confirmation par e-mail.

## Étape 2 : Évaluation du Prix

### Rôles :
- Agent de Réception
- Agent de Connaissance

### Délais :
- Agent de Réception : 24 heures
- Agent de Connaissance : 12 heures

### Étape détaillée :
L'Agent de Réception effectue une recherche de prix et le délai est dépassé si l'Agent de Connaissance n'est pas en mesure de le fournir. Si validé, une notification est envoyée au demandeur avec le coût estimé.

## Étape 3 : Confirmation de Réserve

### Rôles :
- Agent de Réception
- Agent de Connaissance

### Délais :
- Agent de Réception : 24 heures
- Agent de Connaissance : 12 heures

### Étape détaillée :
L'Agent de Réception enregistre la confirmation de réservation. Le délai est dépassé si le demandeur ne reçoit pas de confirmation. Si confirmée, le demandeur reçoit un e-mail de confirmation.

## Étape 4 : Suivi et Retrait

### Rôles :
- Agent de Réception
- Agent de Connaissance

### Délais :
- Agent de Réception : 24 heures
- Agent de Connaissance : 12 heures

### Étape détaillée :
L'Agent de Réception surveille la réservation. Le délai est dépassé si le demandeur ne reçoit pas de notification. Si la réservation est confirmée, le demandeur reçoit un e-mail de notification.

## Conclusion

Ce document présente la procédure internationale de gestion des trajets chez "VoyageExpress". Il met en lumière les rôles, délais et étapes pour assurer une gestion efficace des voyages.
